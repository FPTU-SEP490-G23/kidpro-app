Section 01 • Tổng Quan Hệ Thống

Executive Summary & Kiến Trúc Tổng Thể

Nền tảng Quản lý Mầm non Thông minh KidPro (Smart Preschool Operations Platform)

Mục Tiêu Nghiệp Vụ

Chuẩn hóa toàn diện quy trình vận hành nhà trường: điểm danh AI kết hợp đối chiếu người đón, cảnh báo dị ứng thực phẩm theo thời gian thực cho bếp ăn, dặn thuốc & lưu trữ minh chứng y tế, quản lý học phí tự động VietQR và liên lạc 1-1 giữa Nhà trường - Phụ huynh.

Multi-Schema Isolation

Tách biệt logic cơ sở dữ liệu thành 7 PostgreSQL Schemas: core, academic, attendance, health, kitchen, finance, comms. Bảo vệ tính toàn vẹn dữ liệu, kiểm soát truy cập phân tầng và dễ dàng chuyển dịch sang Microservices trong tương lai.

Công Nghệ Cốt Lõi

  • • Backend: Java 17, Spring Boot 3.3.x, Spring Data JPA
  • • Database: PostgreSQL 15+ (uuid-ossp, pgcrypto, jsonb)
  • • Security: Spring Security 6, JWT Stateless, Method RBAC
  • • Integrations: VietQR / SePay Webhook, FCM Cloud Messaging
Lưu ý quan trọng về Module đã Hủy bỏ (Scrapped): Phân hệ Câu lạc bộ Ngoại khóa (Extracurricular Clubs - skill_clubs, student_club_registrations) đã được **loại bỏ vĩnh viễn** khỏi phạm vi dự án và kịch bản cơ sở dữ liệu `NEWDB.md`. Toàn bộ code liên quan (Entity, DTO, Service, Controller) đã được xóa bỏ sạch sẽ trong Session 2.

Quy ước Layer trong từng Domain

  • • entity/: JPA Entities với định danh @Table(schema="..."). Bắt buộc có @ToString.Exclude trên các trường quan hệ 1-N / N-1 để tránh đệ quy Lombok.
  • • repository/: Spring Data JPA Repositories kế thừa JpaRepository.
  • • service/ & service/impl/: Tách Interface và Implementation. Áp dụng @Transactional cho các thao tác ghi.
  • • dto/request/ & dto/response/: DTOs độc lập, áp dụng chặt chẽ Jakarta Bean Validation (@NotNull, @NotBlank, @Min, @PastOrPresent).

Mô hình Controller: Actor / BFF Separation

Hệ thống phân tách rõ rệt Controller theo ngữ cảnh người dùng và thiết bị:

🖥️ Web Admin & Staff /api/academic, /api/health, /api/kitchen, /api/finance/billing,...
📱 Mobile BFF /api/teachers (Giáo viên), /api/parents (Phụ huynh), /api/chat, /api/notifications

1 Cấu Hình Môi Trường & Cơ Sở Dữ Liệu

Chạy tập lệnh SQL từ file NEWDB.md trên PostgreSQL để khởi tạo extension uuid-ossp, pgcrypto và 7 schemas: 

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE SCHEMA IF NOT EXISTS core;
CREATE SCHEMA IF NOT EXISTS academic;
CREATE SCHEMA IF NOT EXISTS attendance;
CREATE SCHEMA IF NOT EXISTS health;
CREATE SCHEMA IF NOT EXISTS kitchen;
CREATE SCHEMA IF NOT EXISTS finance;
CREATE SCHEMA IF NOT EXISTS comms;

Tạo file .env hoặc cấu hình biến môi trường trong application.yml: 

DB_URL=jdbc:postgresql://localhost:5432/kidpro_db
DB_USERNAME=postgres
DB_PASSWORD=your_password
JWT_SECRET=kidproSuperSecretKeyForJwtAuthenticationSecurityTokenMustBe256BitsLong
PORT=8080

2 Khởi Động & Kiểm Thử Ứng Dụng

Biên dịch mã nguồn và khởi động Spring Boot bằng Maven Wrapper:

Trên Windows PowerShell / CMD:
.\mvnw.cmd clean spring-boot:run
Trên Linux / macOS:
./mvnw clean spring-boot:run
